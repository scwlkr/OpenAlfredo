# Brand

This document defines OpenAlfredo's product language, naming, voice, and visual direction. Use it for public copy, UI text, README changes, and design work.

## Positioning

OpenAlfredo is a local-first agent workspace for people who want conversation, memory, and initiative to continue across sessions on their own machine.

Short description:

> Local-first context for work that does not reset.

## Audience

Primary audience:

- developer-builders who want a local agent with memory, task continuity, and background initiative.

Secondary audience:

- AI power users exploring self-hosted persistent agent workflows.

## Product promise

You return to context, not a blank slate.

## Naming

| Surface | Use |
|---|---|
| Product | OpenAlfredo |
| Technical shorthand | OAX |
| CLI command | `oax` |
| App package | `oax-web` |
| Default agent | Alfredo |

Do not introduce legacy names or unexplained nicknames in active docs.

## Voice

OpenAlfredo should read as:

- steady;
- lucid;
- capable;
- warm without being cute;
- technically candid.

Avoid:

- melodrama;
- violent imagery;
- gore-coded metaphors;
- corporate filler;
- gimmick language.

## Vocabulary

Prefer:

- local-first;
- agent;
- memory;
- continuity;
- workspace;
- AMBITION;
- RESTLESS heartbeat;
- continuity loop.

Avoid:

- chatbot;
- generic bot;
- magic;
- autonomous employee;
- network-ready claims.

## Visual direction

The existing UI palette uses warm paper surfaces, dark ink, basil green primary actions, and brass accents.

| Token | Hex | Use |
|---|---|---|
| `--oax-paper` | `#F4EEDF` | App background. |
| `--oax-shell` | `#FFFAF1` | Cards and chat surfaces. |
| `--oax-ink` | `#171512` | Primary text and dark surfaces. |
| `--oax-basil` | `#2F6B4F` | Primary actions and active states. |
| `--oax-basil-strong` | `#254F3C` | Hover and pressed states. |
| `--oax-brass` | `#B98A3D` | Timing and emphasis. |
| `--oax-sage` | `#8FA08E` | Secondary text on dark surfaces. |
| `--oax-edge` | `#D7CAB3` | Borders and separators. |
| `--oax-muted` | `#666257` | Supporting copy. |

UI changes should stay structured, legible, and operational. Reserve red for genuine errors.
